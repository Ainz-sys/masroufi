# مصروفي — تطبيق آيفون مستقل (SwiftUI)

تطبيق أصلي يحسب مصروفك اليومي من رسائل البنك، بتصميم iOS الافتراضي (بدون ألوان أو تصميم خاص).

## المزايا
1. تسجيل تلقائي من رسائل البنك عبر إجراء «سجّل رسالة البنك» في تطبيق الاختصارات (يعمل بالخلفية بدون فتح التطبيق).
2. فئات مخصّصة: إضافة وتعديل وحذف، مع أيقونة وميزانية شهرية وتنبيه 80٪/100٪.
3. تذكّر التاجر: اختر فئة مرة، وتنطبق على كل عملياته.
4. ميزانية يومية وميزانية دورة وميزانيات فئات، مع تنبيهات 80٪ و100٪.
5. الدورة الشهرية تبدأ من يوم الراتب.
6. ودجت للشاشة الرئيسية (صغير/متوسط) وشاشة القفل، يتحدّث فور تسجيل أي عملية.
7. إضافة يدوية، ولصق رسائل قديمة (عدة رسائل مرة وحدة).
8. تحليل الدورة: حسب الفئة، أكثر التجار، كل يوم، ومقارنة بالدورة السابقة.
9. عربي / English من داخل التطبيق.
10. الخصوصية: البيانات على الجوال فقط ولا اتصال بالإنترنت، وتصدير CSV.
+ شاشات ترحيبية تعليمية، وسؤال Siri «كم باقي لي اليوم؟».

## الملفات
- `Shared/SMSParser.swift` قراءة رسائل البنوك (QNB, QIB, CBQ, بنك الدوحة… عربي وإنجليزي)
- `Shared/Core.swift` البيانات والحفظ والحسابات والتنبيهات والتصدير
- `Shared/L10n.swift` النصوص بالعربي والإنجليزي
- `App/App.swift` التطبيق، والتخزين، والإشعارات، وإجراء الاختصارات
- `App/Views.swift` كل الشاشات
- `Widget/Widget.swift` الودجت
- `project.yml` يولّد مشروع Xcode
- `.github/workflows/build.yml` يبني التطبيق على أجهزة ماك مجانية في GitHub

## البناء بدون ماك
1. أنشئ حساب GitHub مجاني ← New repository (Private).
2. Add file ← Upload files ← ارفع `Masroufi.zip` ← Commit.
3. Add file ← Create new file ← الاسم `.github/workflows/build.yml` ← الصق محتوى الملف ← Commit.
4. تبويب Actions ← انتظر ~10 دقائق ← افتح التشغيل ← نزّل `Masroufi-ipa`.

## التثبيت على الآيفون
أبل لا تسمح بتثبيت تطبيق خارج App Store إلا بتوقيعه بحساب Apple:
- **مجاناً:** برنامج Sideloadly أو AltStore على كمبيوتر ويندوز + Apple ID. التوقيع يصلح 7 أيام ويتجدّد.
- **حساب مطوّر (99$ سنوياً):** التطبيق يبقى سنة كاملة ويمكن تثبيته عبر TestFlight.

## بعد التثبيت
- الإعدادات ← عام ← إدارة الأجهزة والـVPN ← وثّق حسابك (للتثبيت المجاني).
- الأتمتة: الاختصارات ← الأتمتة ← + ← رسالة ← تحتوي على QAR ← تشغيل فوراً ← إجراء «سجّل رسالة البنك» ← الرسالة = مُدخل الاختصار.
